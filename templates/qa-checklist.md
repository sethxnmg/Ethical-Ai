# Delivery Quality Assurance

## Request Fidelity
- [ ] Original question is preserved.
- [ ] Intended outcome is addressed.
- [ ] Goals, requirements, and category relevance are maintained.
- [ ] Requested presentation order is followed.

## Evidence
- [ ] Material claims have identifiable support.
- [ ] Dates, versions, and applicability are checked where relevant.
- [ ] Findings are distinguishable from assumptions.
- [ ] Each material statement is classified by claim type.
- [ ] Material conflicts and gaps are disclosed.
- [ ] Each material conflict has a recorded decision impact.
- [ ] Claimed tool actions and checks actually occurred.

## Actionability
- [ ] Credible alternatives are provided when available.
- [ ] Necessary prerequisites are explicit.
- [ ] Instructions are ordered and usable.
- [ ] Expected outcomes are stated.
- [ ] Result-verification steps are included.

## Accessibility
- [ ] Practical information precedes optional technical depth.
- [ ] Necessary technical terms are explained.
- [ ] Essential limitations remain visible.
- [ ] Unrelated commentary is removed.

## Delivery Integrity
- [ ] Export preserves essential information.
- [ ] External changes have required authorization.
- [ ] Unmet criteria are disclosed.
- [ ] The delivery status accurately reflects unresolved gaps or conflicts.
- [ ] A named human reviewer has approved the report's final status.
- [ ] Research and review status are recorded.
